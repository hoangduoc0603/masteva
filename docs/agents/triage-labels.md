# Triage Labels

Các skill nói theo năm vai trò triage chuẩn. File này ánh xạ từng vai trò sang chuỗi thật dùng trong tracker của repo (dòng `Status:` của file issue trong `.scratch/`).

| Label trong mattpocock/skills | Label trong tracker | Nghĩa                                       |
| ----------------------------- | ------------------- | ------------------------------------------- |
| `needs-triage`                | `needs-triage`      | Chủ dự án cần xem và đánh giá issue này     |
| `needs-info`                  | `needs-info`        | Đang chờ người báo bổ sung thông tin        |
| `ready-for-agent`             | `ready-for-agent`   | Đã đặc tả đủ, agent tự làm được             |
| `ready-for-human`             | `ready-for-human`   | Cần người làm                               |
| `wontfix`                     | `wontfix`           | Sẽ không làm                                |

Khi skill nhắc tới một vai trò (ví dụ "apply the AFK-ready triage label"), dùng chuỗi tương ứng trong bảng này.

Sửa cột "Label trong tracker" nếu muốn dùng tên khác.
