JDK, bản phân phối và phiên bản LTS

JDK gồm trình biên dịch javac, máy ảo java và thư viện chuẩn. Nhiều hãng phát hành bản build từ cùng mã nguồn OpenJDK; với dự án mới, chọn một bản LTS (hiện là 21 hoặc 25) để có bản vá trong nhiều năm.

  • Oracle Java SE Support Roadmap: Lịch hỗ trợ của từng phiên bản, bản nào là LTS.
  • Eclipse Temurin: Bản build OpenJDK miễn phí, phổ biến nhất để cài.
  • OpenJDK: JDK Project: Lịch phát hành và danh sách JEP theo phiên bản.

java, javac, jshell

javac biên dịch mã nguồn thành bytecode, java chạy bytecode trên JVM, còn jshell cho thử từng dòng mà không cần tạo lớp. Từ JDK 22, lệnh java chạy thẳng được chương trình gồm nhiều file nguồn.

  • Lệnh javac (Java SE 25): Tham số dòng lệnh: classpath, release, encoding.
  • JEP 458: Launch Multi-File Source-Code Programs: Chạy chương trình nhiều file mà không cần biên dịch trước.
  • JShell trên dev.java: Hướng dẫn chính thức về REPL của Java.

IntelliJ IDEA hoặc VS Code

Chọn một IDE và dùng thành thạo: IntelliJ IDEA hiểu sâu Java và Spring, VS Code nhẹ hơn khi cài Extension Pack for Java. Điều quan trọng là phím tắt điều hướng, refactor và chạy test, không phải IDE nào.

  • IntelliJ IDEA: Getting started: Tạo project, chạy, refactor cơ bản.

Debugger

Debugger dừng chương trình ở breakpoint để xem biến và đi từng bước, nhanh và chính xác hơn rải System.out.println. Cần biết breakpoint có điều kiện, step into/over/out và evaluate expression.

  • IntelliJ IDEA: Debug code: Breakpoint, step, watch, evaluate.
  • Debugging Java in VS Code: Cấu hình launch và các thao tác debug.

Git cơ bản

Git lưu lịch sử thay đổi của mã nguồn. Ở cấp nền tảng cần commit, branch, merge, rebase đơn giản, gỡ xung đột và làm việc với remote qua pull, push.

  • Pro Git: Sách chính thức, miễn phí; đọc chương 1 đến 3.
  • Learn Git Branching: Luyện branch, merge, rebase trực quan, có tiếng Việt.

Đọc tài liệu API và Javadoc

Javadoc của JDK trả lời chính xác một lớp làm gì, ném exception nào, có an toàn khi chạy đồng thời không. Tập tra nó trước khi tìm trên mạng, và viết Javadoc cho API công khai của chính mình.

  • Java SE 25 API: Tài liệu API của JDK, có ô tìm kiếm.
  • Lệnh javadoc (Java SE 25): Sinh tài liệu từ chú thích trong mã.
  • Javadoc trên dev.java: Cách viết chú thích Javadoc đúng chuẩn.
