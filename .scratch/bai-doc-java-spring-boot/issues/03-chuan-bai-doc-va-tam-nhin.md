# 03: Chuẩn bài đọc, tầm nhìn sản phẩm và danh sách cố ý không dạy

**What to build:** Tác giả (agent viết bài) có một chuẩn rõ để viết bài đọc; tài liệu sản phẩm không còn mâu thuẫn với ADR-0011; người học thấy trên trang roadmap những công nghệ nào cố ý không dạy và vì sao.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Chuẩn nội dung có phần bài đọc: khung ba phần, cách viết phần kiến thức theo kết quả nghiên cứu ở 01, quy tắc ví dụ code và output, chỗ đặt callout "Trên production", "Khi làm cùng AI", "Liên hệ bài khác"
- [ ] Chuẩn nội dung có cách chuyển một bài lab cũ thành bài đọc: nhập kiến thức phần đào sâu, nhập phát hiện từ lab kèm output tiêu biểu, chép câu hỏi–lời giải vào nguồn câu hỏi phỏng vấn (định dạng nguồn mô tả ở đây), xoá mã mục cũ khỏi file khoá
- [ ] Định nghĩa `verified` của bài đọc: mọi đoạn code và output đã chạy thật với phiên bản ghi kèm; khẳng định về hành vi API có tài liệu chính thức hoặc output làm dẫn chứng
- [ ] Tầm nhìn sản phẩm ghi giá trị cốt lõi mới: bài đọc đầy đủ và sâu; thực hành ở dự án; ôn phỏng vấn ở bộ câu hỏi phỏng vấn; bài lab giữ cho DevOps và Kubernetes
- [ ] Mô tả roadmap Java và Spring Boot ghi danh sách cố ý không dạy kèm lý do: Bazel, Javalin, Play, EBean, TestNG, Cucumber, Log4j2/TinyLog, JSP
- [ ] `pnpm content:check` xanh
