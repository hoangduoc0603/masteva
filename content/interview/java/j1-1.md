# j1.1 · JDK, javac, java và jshell

Nguồn cho bộ câu hỏi phỏng vấn, chép nguyên văn từ phần Đào sâu khi chuyển bài lab sang bài đọc. Chưa hiển thị trên trang. Định dạng: `docs/content-standard.md` §3.7.

## Đã có java Main.java, sao dự án thật vẫn cần javac hay Maven?

Chế độ chạy từ mã nguồn biên dịch lại toàn bộ mỗi khi bạn gọi `java` và không tạo file `.class` hay `.jar`. Nó không quản lý thư viện bên ngoài, không chạy test, không đóng gói. Nó hợp với script, ví dụ, bài tập. Dự án có nhiều package và dependency cần build tool như Maven hoặc Gradle, học ở J7.

## Vì sao nên dùng --release thay vì -source và -target?

`-source 21 -target 21` chỉ đổi cú pháp được phép và version bytecode, nhưng vẫn biên dịch với thư viện chuẩn của JDK 25. Code có thể gọi một method chỉ có từ Java 25, biên dịch thành công, rồi chết với `NoSuchMethodError` trên JVM 21. `--release 21` kiểm tra cả API, nên lỗi lộ ra ngay lúc biên dịch.

## Java 25 có cách viết main ngắn hơn không?

Có. Từ Java 25 (JEP 512), một file chỉ cần `void main() { IO.println("Xin chao"); }`, không cần `public class` hay `static`. Cách này dành cho chương trình nhỏ và người mới học. Code trong các dự án hiện tại vẫn dùng `public static void main(String[] args)`, nên bạn cần đọc được cả hai.
